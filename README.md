#  Sistema Web de Portafolios y Gestión de Asesorías

Este proyecto corresponde al desarrollo de una aplicación web tipo portafolio administrable, donde programadores pueden mostrar sus proyectos y los usuarios externos pueden agendar asesorías.  

El sistema integra un frontend desarrollado en Angular y un backend robusto en Jakarta EE, con persistencia en base de datos relacional PostgreSQL.

El proyecto fue desarrollado como parte del Proyecto Integrador de la asignatura Programación y Plataformas Web.

---

##  Tecnologías Utilizadas

### Frontend
- Angular
- TypeScript
- HTML
- SCSS

### Backend
- Jakarta EE
- JAX-RS (Servicios REST)
- JPA (Persistencia de datos)

### Base de Datos
- PostgreSQL

### Otros
- Envío de correos automáticos
- Arquitectura cliente-servidor

---

##  Roles del Sistema

### Administrador
- Crear, editar y eliminar programadores
- Registrar horarios de disponibilidad
- Visualizar reportes administrativos

### Programador
- Gestionar su perfil
- Registrar proyectos en su portafolio
- Aprobar o rechazar asesorías

### Usuario Externo
- Explorar portafolios
- Agendar asesorías
- Recibir notificaciones por correo

---

##  Funcionalidades Principales

Gestión de usuarios y roles  
Portafolios individuales por programador  
Registro de proyectos académicos y laborales  
Gestión de disponibilidad de horarios  
Sistema de asesorías con validación de horas ocupadas  
Notificaciones automáticas por correo  
Reportes administrativos tipo dashboard  
Persistencia en base de datos relacional
